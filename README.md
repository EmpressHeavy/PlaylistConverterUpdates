# PlaylistConverterUpdates 🎶

The official update source for the **Playlist Converter** Grok Bot: copies playlists between music apps (Apple Music, Spotify, YouTube / YouTube Music, others), with a private memory backed up to your own private GitHub repo.

## Upgrade your Playlist Converter (for owners)
1. Copy this page's link: `https://github.com/EmpressHeavy/PlaylistConverterUpdates`
2. Open your Playlist Converter chat, paste the link, and say: **"upgrade yourself from this repo"**
3. It tells you what's new and upgrades. Your memory, past conversions and settings are kept.

After that, updates are **automatic and always on**: once a week the bot checks this repo and, if there's a newer version, updates itself and sends you a short note. This is built in and can't be switched off (you can move the time it runs).

## Safety promises
- The bot only accepts updates from this exact repo.
- Update files can never make the bot move money, send messages, or handle your logins or passwords. You always sign in yourself.
- Hive Mind (anonymous lesson sharing) is off unless you turn it on, and it's send-only.
- Your memory is never overwritten. A snapshot is taken before every update and rolled back if anything fails.
